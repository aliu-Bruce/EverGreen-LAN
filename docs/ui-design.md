# EverGreen LAN(UI)界面设计规范

> 版本:v3 · 配套交互原型:`docs/ui/mockup.html`
> v3 修订:确立"温室"设计语言,替换 v2 "网络仪表"的冷硬气质;字体改为本地资源文件
> (SIL OFL 授权,下载与声明生成方式:`assets/fonts/fetch-fonts.ps1` → `docs/ui/fonts.css`);
> 动效确立为"出现即淡入,离开即淡出"的统一规范。
> v2 的问题:全 hairline 分层 + 零阴影 + DIN 字体,严格有余而温度不足。
> v3 保留 v2 的全部结构性决定(双导航、令牌制、数据表形态、像素身份收缩),只更换材质与动效。

---

## 1. 设计原则

1. **暖纸与深常绿构成材质**:浅色主题是奶油纸面,深色主题是深常绿木板;两者是同一种"温室"的两面,不是两套配色。
2. **全无衬线构成统一声音**:页面标题、主行动与正文共用 Hanken Grotesk 无衬线可变字体,汉字统一回退 Noto Sans SC;衬线字族已下架,不参与任何文字角色。
3. **等宽字体只给真实数据**:虚拟 IP、端口、MTU、延迟、房间码、版本号(JetBrains Mono,亦为无衬线字形)。
4. **柔和阴影承担物理层次**:v3 允许阴影,但必须带偏移与模糊(禁止零偏移光晕);深色主题阴影收敛为压暗,浅色主题阴影带暖棕色调。
5. **单色纪律不变**:品牌绿只出现在主行动、选中态、状态指示;琥珀=中继/警告,红=危险。
6. **像素身份收缩三处**:Logo、空状态插画、房间码角括号。控件与正文绝不像素化。
7. **晨雾底光**:两团极低透明度的氛围光构成背景材质,来源于"温室"意象,不属于装饰性渐变。
8. **动效既表达进入,也表达状态变化**:出现与离开淡入淡出并有交错;换色、换主题、选中与按压另用 emphasized 缓动与轻微回弹表达"落定",不做纯装饰性运动。

## 2. 字体(本地资源文件,SIL OFL 1.1 授权)

字体作为资源文件入库,不构成运行时代码依赖(符合依赖红线策略)。
同一角色内,拉丁字符与汉字按 unicode-range 自动分流——"每个字都有自己指定的字体"。

| 角色 | 拉丁字族 | 汉字字族 | 字重/轴 | 文件位置 |
|---|---|---|---|---|
| 标题/主行动 | Hanken Grotesk(可变 300..800) | Noto Sans SC | 700 | `assets/fonts/en/` · `assets/fonts/zh/` |
| 正文/控件 | Hanken Grotesk(可变 300..800) | Noto Sans SC | 400 / 700(加粗开关) | 同上 |
| 数据 | JetBrains Mono(可变 100..800) | (无汉字数据) | 400 | `assets/fonts/en/` |

- 字体栈:`--font-display: "Hanken Grotesk","Noto Sans SC",sans-serif`;`--font-text` 同族;`--font-mono: "JetBrains Mono","Noto Sans SC",monospace`。
- 界面上所有文字必须显式归入三个角色之一,不允许裸继承系统字体;Flutter 端由 `egDisplay / egText / egMono` 统一施加字号缩放、汉字回退与 `wght` 轴。
- 中文切片按 unicode-range 拆分(每字族约 100 片),浏览器只加载页面实际用到的切片。
- 重建方式:`assets/fonts/fetch-fonts.ps1`(可重复执行);授权与来源:`assets/fonts/LICENSE-NOTE.md`;Flutter 端仅声明 Hanken Grotesk / JetBrains Mono / Noto Sans SC 三族,Fraunces 与 Noto Serif SC 的字体声明已从 `pubspec.yaml` 移除。

## 2.5 多语言与默认用户名

- 语言包:界面实际加载 `ui/assets/langs/{zh-Hans,zh-Hant,en,ja,ko,ru,es}.json`;根目录 `assets/langs/` 是供 HTML 原型使用的同名副本,由 `ui/test/langs_test.dart` 保证同步。扁平点分键(如 `room.shareHint`),`$meta.name` 为该语言自称名;7 份文件键集必须一致(当前各 250 键)。
- 占位符:`{x}` 形式(如 `{room}` `{n}` `{code}` `{ms}`),由渲染层在填充时替换;数字与演示数据不属于语言包。
- 语言下拉:选项以语言自称名显示(简体中文/繁體中文/English/日本語/한국어/Русский/Español),选择即时生效并同步 `<html lang>`;无网络请求依赖,原型经相对路径读取语言包。
- 默认用户名:`Player-` + 系统用户名清洗结果——仅保留字母数字与 `_.-`,清洗后为空则回退 `Player`,总长 ≤ 24 字符;仅为本地默认值,设置中可改,修改即时反映到侧栏身份与成员表。

## 3. 色彩令牌(双主题同步)

| 令牌 | 用途 | 深色 | 浅色 |
|---|---|---|---|
| `bg` / `bg2` | 窗口底 / 原型控制条 | `#101913` / `#0C130E` | `#F2EDE2` / `#EBE4D4` |
| `panel` / `panel2` | 面板 / 悬停与次级面 | `#18231C` / `#202D25` | `#FBF8F0` / `#F1EBDD` |
| `line` / `line2` | hairline / 控件描边 | `#2A3A30` / `#3D5145` | `#E5DCC8` / `#CDC2A7` |
| `text` / `muted` / `faint` | 主文本 / 次要 / 弱注记 | `#EDE9DC` / `#A5B1A1` / `#71806F` | `#272E26` / `#5D6455` / `#9B9E8C` |
| `acc` / `acc-ink` / `acc-dim` | 主行动、选中、状态 | `#C7E28B` / `#16240F` / `#2B3D24` | `#2F5D43` / `#F7F4EA` / `#E1EBDA` |
| `warn` / `warn-dim` | 中继、警告 | `#D9A968` / `#43301B` | `#8A5E1E` / `#F4E8D2` |
| `bad` / `bad-dim` | 危险、错误 | `#E08B76` / `#46231B` | `#A8452F` / `#F6E2DC` |
| `washA` / `washB` | 晨雾底光两团 | 绿 10% / 暖 6% | 绿 8% / 暖 10% |
| `shadow` / `panel-shadow` / `acc-shadow` | 弹层 / 面板 / 主按钮 | 压暗 | 暖棕 |

- 对比度:正文与次要文本 ≥ 4.5:1;`faint` 仅承载装饰性注记,不承载必读信息。
- 表中数值是默认 seed 的呈现;用户在外观里改主色后,`ColorScheme.fromSeed(... fidelity)` 重新推出 `acc / accInk / warn / bad` 等语义色,其余令牌保持同一命名。`accDim` 取主色薄涂于surface,而非 fidelity 下会与深 seed 撞色的 `primaryContainer`。
- 深色默认(夜晚开黑场景);两套主题共用同一套令牌名,任何颜色不得写死。

## 4. 几何与状态

- M3 Expressive 形状语言:按钮、输入框、分段、开关、设置行容器一律药丸形(半径 100);面板 24 / 弹层 30。外观分组头采用 40px 花瓣形色标(十瓣余弦波轮廓),选中预设在圆→圆角方之间变形。
- 圆角缩放 `radiusScale` 作用于全部角半径(0–1.3);大于 1.25 时由 `autoRadiusTextAdjust` 轻微收紧文字,避免文字被圆角吃掉。
- 阴影规范:主按钮 `0 8px 20px`;面板浅色 `0 1px 2px`、深色无;弹层 `0 24px 60px`。全部带偏移与模糊。
- 焦点环 2px `acc` 外扩 2px;文本选区、滚动条、光标随主题。
- 每个交互控件具备:默认/悬停/按下/焦点/禁用 五态;悬停上浮 1–2px 并轻微放大,按下以 emphasized 曲线回弹(缩放 .86–.96)。

## 5. 布局骨架:双导航模式

- **侧栏(216px)**:品牌区(应用图标 `assets/icon/icon.png` + 无衬线 EGLAN 字标)→ 文字导航(活动项=浅底+4px 方点)→ TUN 状态块 → 本机头像。
- **顶栏(56px)**:品牌居左,标签页居中(活动项 2px 下划线),右端连接状态。
- 内容区最大宽 880px;窗口最小 720×520。

## 6. 页面规格

### 6.1 主页
- 状态条:本机虚拟 IP / MTU / UDP 端口(mono)。
- 不对称主行动:创建房间 = 主色实心大块(无衬线重标题);加入房间 = 描边块。
- 房间表置于软面板中:房间 | 房主 | 成员 | 延迟 | 连接 | 加入;延迟带状态灯。

### 6.2 房间页
- 无衬线重标题(30px)+ 身份注记;头部只留"二维码"。
- **房间码块 = 全页唯一记忆点**:软面板 + JetBrains Mono 26px 绿色码文 + 四角像素角括号(悬停变绿)。
- 成员表;MC 联机指引折叠面板(mono 编号 01/02/03);底部退出房间(危险描边)。

### 6.3 加入流程
- 三段 mono 输入框(焦点描边变绿 + acc-dim 光圈)。
- 连接过程 = 控制台输出(`>` 前缀逐行);失败为红描边块 + 具体原因 + 重试。

### 6.4 传输(预留)
空态:像素链环插画 + 一行说明;上线后为收发列表。

### 6.5 设置
分组软面板,所有设置按列堆叠(标题+注脚+右侧控件)。外观分类用一条紧凑的分组头代替大 hero:主色花瓣色标 + 17px 标题 + 单行说明 + 反色「恢复默认」药丸,高度约 64px,不占首屏。

- 主色:调色盘圆盘按钮 + `#RRGGBB` 输入框双向同步、整体靠右;彩虹预设红/橙/黄/绿/青/蓝/紫,选中时圆→圆角方变形并放大。调色盘弹层含饱和度/明度面板、色相条、三个精确滑块与预览,拖动 90ms 防抖、松手立即写盘。
- 字体:显示标题固定为无衬线,不开放选择;仅正文/等宽两个下拉,候选限定 Hanken Grotesk / JetBrains Mono / Noto Sans SC,说明中不出现"显示标题"字样。全局「加粗字体」开关统一提升字重(400→700、700→800)。
- 字号 0.85–2.0、圆角 0–1.3:步进器为「− [数值框] +」,± 不被压扁,数值框保持足够宽度。下方实时预览浅/深两块色板。
- 所有改动即时生效并平滑过渡,统一由「恢复默认」还原。

其余控件右对齐:分段控件(含"跟随系统")/ 开关 / mono 输入框;用户名行(默认 `Player-系统用户名`,修改即时反映到侧栏身份区与成员表);语言为自定义下拉组件(7 种语言以自称名呈现,触发器 + 浮出菜单,方向键可用,选中项以 acc-dim 底标注;展开时所在分组提升 z 序,避免被后续分组遮挡,贴近底部向上展开且可滚动);STUN 服务器可编辑,试连成功后才保存,并提供重置与信任提示;关于组含版本 + 构建哈希。

### 6.6 首次启动引导与弹层
全屏弹层:背景模糊 + 压暗,面板 22px 圆角、大阴影;三步(欢迎/权限边界/就绪),步进点为胶囊形;二维码弹层同构。

## 7. 动效规范(淡入淡出 + emphasized 落定)

出现与离开沿用项目缓动 `cubic-bezier(.22,.75,.3,1)`;状态变化与 M3 语义动效用 `cubic-bezier(.2,0,0,1)`(emphasized);`prefers-reduced-motion` 下全部动画与过渡静止。

| 场景 | 时序 |
|---|---|
| 页面进入 | 整页 fadeIn 260ms + 3% 下滑 + 0.985→1 缩放;子元素 fadeUp 540ms,交错 60ms/项,带轻微回弹 |
| 页面离开 | 与进入同帧交错,旧页淡出上移,无等待空档 |
| 表格行 | fadeUp 500ms,基数 140ms 后交错 50ms/行 |
| 侧栏/顶栏 | 初次显示时子项交错 40–45ms 淡入 |
| 弹层开关 | 过渡 240ms(背景淡入 + 面板 0.94→1 缩放淡入,expressed 缓动) |
| 换色/换主题 | 令牌插值 420ms emphasized:背景、表面、文字、主色连续过渡;系统控件同速;reduce-motion 下瞬切 |
| 预设色块选中 | 圆→圆角方变形 + `easeOutBack` 放大 1.12,按下回弹 0.86 |
| 下拉菜单 | 打开 180ms 上浮淡入(scale .97→1),关闭 160ms 淡出;触发器箭头 180ms 旋转 |
| 导航模式切换 | 旧形态 200ms 滑出淡出,新形态 220ms 滑入淡入;连点时取消未完成的切换 |
| 引导步骤 | 旧步骤 150ms 淡出 → 新步骤子项交错淡入 |
| 控件悬停/按压 | 160ms 过渡,上浮 1–2px / 回落 1px;分段控件与原型条按钮按压再缩至 .93–.97 |
| 侧栏滑点 | 整栏唯一状态点,切页时自旧项滑向新项 360ms(emphasized 缓动),途中拉伸为约 2.4× 竖条,到位收回;悬停图标右移 2px |
| 顶栏滑线 | 整条唯一滑线,切页时自旧页签滑向新页签(left+width 同步 320ms emphasized);指示器与页面进入同时发生 |
| 指示器就位 | 换导航形态或窗口缩放时以 .snap 瞬时就位,不播放滑动 |
| 入场填充 | 交错入场一律 fill-mode backwards(非 both),避免动画填充锁死悬停 transform |
| 房间码校验 | 码段不完整点连接:输入区 shake 400ms 左右抖动并取消跳转;满 4 位自动跳格 |
| 复制反馈 | 按钮变 acc-dim/acc 底 160ms,1.2s 后还原 |
| 引导折叠 | 摘要悬停变 acc;展开时步骤条目 fadeUp 交错 60ms;折叠箭头着 acc 色 |
| 开关/拖放区 | 开关按住时滑钮 scaleX 1.35 捏扁;拖放区悬停描边转 acc 并上浮 2px |
| 状态灯呼吸 | pulse 2.4s 循环 |

### 7.1 M3 融合要点(参考 material.io,取其语义不改其色)

- **emphasized 缓动**:`--ease-emph: cubic-bezier(.2,0,0,1)` 用于指示器滑动、换色令牌插值与状态落定;出现/离开沿用项目自身缓动。
- **胶囊形活动项**:侧栏活动项与悬停底色为全圆角胶囊(M3 导航态),属于圆角阶梯的既定例外。
- **状态层**:悬停 8% / 按压 12% 的 currentColor 叠加,覆盖导航项、页签、按钮、下拉项、分段与原型条控件;主按钮不再用亮度悬停。
- **触感涟漪**:按下处生成 2.2× 最大边的圆形扩散(currentColor 14%→0,550ms emphasized),动画结束自净;`prefers-reduced-motion` 下不生成。
- **开关语义**:选中后拇指放大(16→18px)并着 on 色,按住捏扁保留。
- **单一指示器**:滑点(.rdot)与滑线(.ind)是整栏/整条唯一的活动指示,语义同 M3 的 navigation active indicator 与 tab indicator。
- **Expressive 出处**:参考 `m3.material.io` 与 Google 设计-library 的 Expressive 插图/研究,取其高饱和主色容器、超大无衬线重标题、药丸控件、花瓣/波状形状与弹性落定;不照搬其示例配色与插画。
- **形状与颜色一起说状态**:选中态不只换色,还改变圆角/尺寸(圆→圆角方、按钮按压缩放),配色切换时全树令牌插值,避免局部突变。

## 8. 外观设置

界面只消费第 3、4 节令牌。主题模式支持浅色/深色/跟随系统。

设置页「外观」分类直接暴露可自定义项:

- **主色**:调色盘按钮 + `#RRGGBB` 输入框双向同步、靠右排列;调色盘弹层含饱和度/明度面板、色相条、H/S/V 精确滑块与预览,拖动 90ms 防抖、松手立即写盘;彩虹预设红/橙/黄/绿/青/蓝/紫,点击后 Hex 同步。
- **字体**:全无衬线,EgFonts.display = EgFonts.text = Hanken Grotesk,汉字回退 Noto Sans SC;显示标题不可改、说明中不出现"显示标题";仅正文/等宽可切换,候选限定 Hanken Grotesk / JetBrains Mono / Noto Sans SC 三族。
- **字重/字号/圆角**:全局「加粗字体」开关把 400→700、700→800、其余就近升档;字号 0.85–2.0、圆角 0–1.3,步进器为「− [数值框] +」;圆角超过 1.25 时由 `autoRadiusTextAdjust` 收紧文字。
- **配色引擎**:`ColorScheme.fromSeed(..., dynamicSchemeVariant: fidelity)` 从主色推出 M3 调色板,fidelity 保留选定色相与饱和度;`accDim` 以主色薄涂 surface 计算,避免与深 seed 撞色。`EgMotion` 对全部令牌插值 420ms,尊重 reduce-motion。
- **持久化**:改动即时生效并写入 `prefs.appearance`;统一「恢复默认」还原 seed、字体、字号、圆角与加粗开关。

没有主题包/预设主题/导入/JSON 编辑器/AI 提示词概念;阴影与布局不变。
