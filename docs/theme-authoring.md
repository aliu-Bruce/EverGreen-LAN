# 自定义主题

主题不是代码，是一份 JSON。在 **设置 → 主题 → 导入主题文件…** 选中即可生效，
格式说明与提示词都直接显示在同一页，不需要去找任何文件。

## 怎么用

1. 打开设置页，点「查看格式」，把模板复制出来改成你要的颜色
2. 另存为任意 `.json`
3. 点「导入主题文件」，选中它
4. 主题立刻出现在网格里并被选中

自定义主题卡片右上角有 × ，点击后会先弹出确认再删除。

改坏了不要紧：设置页底部的「重置默认主题」会清空所有自定义主题，并把四个内置主题恢复到
src/builtin-themes.json 里的原始定义，界面回到默认的 Pine。该操作同样有确认弹窗。

内置主题的覆盖值单独存放在本地，不会改动源文件——所以随时可以恢复。

不想碰文件也能做，两条路：

- **可视化**：网格末尾的虚线卡「新建」打开空白编辑器；选中任意主题（含内置的四个）后点「编辑」会直接覆盖它。
  颜色、标题字体、小字字体、字重（100–700）、圆角与字号（上限 130%）都可调，实时预览。
  分隔线、强调文字色与颗粒强度会按明暗自动推导，不需要手写。
- **JSON**：同一个弹窗切到「JSON」分页，是带行号的代码区，预填了完整格式示例。
  你可以整段粘贴别处生成的主题，保存时同样会校验。

导入的主题保存在本机（应用数据区），与偏好一起持久化，不依赖外部文件。
不会写字也行：点「让 AI 写一个」，把提示词整段复制给对话模型，让它按你的描述生成。

## 文件格式

```json
{
  "schemaVersion": 1,
  "name": "海盐",
  "hint": "冷蓝 · 细衬线",
  "mode": "light",
  "vars": {
    "bg": "#eef3f6",
    "ink": "#0d1b24",
    "accent": "#1f6f8b"
  }
}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `schemaVersion` | 否 | 当前为 `1`；省略按 1 处理，其他值会被拒绝 |
| `name` | 是 | 显示在主题卡片上的名称，最多 24 字符 |
| `hint` | 否 | 卡片右下角的短说明 |
| `mode` | 否 | `light` 或 `dark`，决定 `color-scheme`；省略按 `light` |
| `vars` | 是 | CSS 自定义属性，键不带 `--` 前缀，必须含 `bg` 与 `ink` |

## 可用变量

| 变量 | 作用 |
|---|---|
| `bg` | 页面底色 |
| `bg-deep` | 次级底色（浮层、选区） |
| `ink` | 主文字色 |
| `ink-soft` | 次级文字色 |
| `ink-faint` | 弱化文字、分隔标签 |
| `rule` | 细分隔线 |
| `rule-strong` | 强分隔线、输入框下划线 |
| `accent` | 强调色（第二行标题、状态点） |
| `accent-ink` | 强调色上的文字色 |
| `alert` | 警告文字色 |
| `grain` | 颗粒强度，0–0.1 之间的小数 |
| `text-scale` | 界面字号倍率，0.85–1.5，默认 1 |
| `radius` | 圆角半径，如 `4px`；省略为直角 |
| `font-body` | 正文字体族 |
| `font-mono` | 等宽字体族 |
| `display-font` | 标题字体族 |
| `display-cjk` | 标题的中文字体族 |
| `display-weight` | 标题字重，如 `600` |
| `display-tracking` | 标题字距，如 `-0.02em` |
| `display-leading` | 标题行高，如 `0.94` |
| `display-size` | 标题字号，如 `clamp(48px, 6.6vw, 88px)` |

未提供的变量沿用内置 Paper 主题的值，因此只写 5–6 个颜色也能得到完整主题。

## 限制与自动修正

- 键必须在上述白名单内，其余键会被忽略（不报错）
- **颜色类变量**必须是十六进制、`rgb()`/`rgba()` 或 `hsl()` 写法；写错会直接报出字段名
- 必须提供 `bg` 与 `ink`
- 单个值不超过 200 字符，且不允许出现 `url(`、`@import`
- 文件带 BOM 也能正常导入（记事本默认会加）
- 导入失败时设置页会直接显示原因，不会静默忽略
- **强调色会被自动修正**：渲染时计算 `accent` 与 `bg` 的对比度，低于 4.5:1 就沿 `mode`
  指定的方向逐步调亮或调暗，直到达标。因此写得偏淡也不会出现看不清的强调文字

## 交给 AI 生成

界面上的「让 AI 写一个」给出的就是这段提示词，也可以直接复制：

```text
为 EverGreen LAN 生成一个界面主题 JSON。请直接按下面给出的文件格式输出。

文件格式（完整示例，请严格沿用这个结构）：
{
  "schemaVersion": 1,
  "name": "海盐",
  "hint": "冷蓝 · 细衬线",
  "mode": "light",
  "vars": {
    "bg": "#eef3f6",
    "bg-deep": "#e2eaef",
    "ink": "#0d1b24",
    "ink-soft": "#2f4350",
    "ink-faint": "#6f8492",
    "rule": "rgba(13, 27, 36, 0.14)",
    "rule-strong": "rgba(13, 27, 36, 0.38)",
    "accent": "#1f6f8b",
    "accent-ink": "#eef3f6",
    "alert": "#9c3b2f",
    "grain": "0.03",
    "radius": "2px",
    "text-scale": "1",
    "display-font": "var(--font-sans)",
    "display-cjk": "var(--font-cjk-sans)",
    "display-weight": "500",
    "display-tracking": "-0.015em",
    "display-leading": "0.98"
  }
}

输出要求：
1. 只输出一个 JSON 对象，不要解释文字，不要 Markdown 代码块。
2. schemaVersion 固定为 1；name 是两到四个汉字的主题名；hint 是「风格 · 字体」形式的短句，
   不超过十个汉字；mode 取 "light" 或 "dark"。

颜色（必填 bg 与 ink）：
3. 必须是合法的 CSS 颜色值（十六进制、rgb 或 rgba）。
4. rule 与 rule-strong 用 rgba，透明度分别在 0.10–0.16 与 0.32–0.40。
5. alert 是该主题下可读的警告色。
6. 正文与背景对比度不低于 7:1，弱化文字不低于 4.5:1。

排版：
7. display-font 只能取 "var(--font-sans)"（无衬线）或 "var(--font-serif)"（衬线）；
   display-cjk 与之配套取 "var(--font-cjk-sans)" 或 "var(--font-cjk-serif)"。
8. display-weight 取 300、400、500 或 600。
9. display-tracking 在 -0.05em 到 0.02em 之间；紧凑风格取负值，松弛风格取 -0.02em 到 0。
10. display-leading 在 0.85 到 1.15 之间；紧凑风格偏小，松弛风格偏大。
11. text-scale 是界面字号倍率，取值 0.85–1.5，默认 1。

形状与质感：
12. radius 是圆角半径，带单位，取值 0px–16px；0px 代表完全直角。
13. grain 是颗粒强度，取值 0.01–0.08。
14. 整体风格克制、留白多、不要霓虹色；强调色只用于少量点缀。

风格描述：<在这里填写，例如「雨天的青灰，配一点旧铜色，衬线标题」>
```
