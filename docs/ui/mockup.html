欢迎来到 EGLAN

创建一个房间,把房间码发给朋友——

大家的游戏会以为彼此在同一个局域网里。

为什么需要管理员权限

联机需要在本机创建一块虚拟网卡,让游戏看到"局域网"。创建它需要一次管理员授权。

权限边界
  • 01虚拟网卡只路由 10.66.x.x 房间地址段,日常上网不经过本软件
  • 02联机数据全程端到端加密,任何第三方无法解读
  • 03不依赖固定服务器,零遥测,源代码开放可审计
