# EverGreen LAN · P0 运行手册

> 目标:在两台机器之间,用 EGLAN 自建的虚拟局域网跑通 ping。
> 全程无中心服务器;本机只与对端建立一条加密 UDP 通道。

## 0. 前置条件

| 项 | 说明 |
|---|---|
| Go 1.24+ | 构建 core 用 |
| wintun.dll(仅 Windows) | 从 wintun.net 下载,放在编译产物同目录;驱动接口属系统组件,不随源码入库 |
| 管理员权限(仅真实模式) | 建虚拟网卡与配地址是系统级操作,提权弹窗属预期 |
| 两台机器互通 | 同一局域网,或任一可直连的网络路径;UDP 端口 47777 可达 |

## 1. 构建

```powershell
cd core
go build -o ..\egland.exe ./cmd/egland
```

## 2. 免管理员自检(建议先跑)

进程内完成握手、双向加密回声、防重放校验,不建网卡:

```powershell
.\egland.exe -test-echo
```

预期输出 5 行 PASS 与「全部通过」。

## 3. 两机 ping 实测

**主机(建房间的一侧,默认隧道地址 10.66.7.1/24):**

```powershell
# 以管理员身份打开 PowerShell
cd <exe 所在目录>
.\egland.exe -role host
# 窗口保持打开;记下自己的局域网 IP(ipconfig 里 WLAN/以太网的地址)
```

**客人(加入的一侧,默认隧道地址 10.66.7.2/24):**

```powershell
# 以管理员身份打开 PowerShell
.\egland.exe -role client -peer 192.168.x.x:47777   # 换成主机的局域网 IP
```

**验证(客人侧):**

```powershell
ping 10.66.7.1        # 打到主机的隧道地址,即穿过整条加密隧道
```

预期:10.66.7.1 全部 Reply。主机侧 `ping 10.66.7.2` 同理可用。

## 4. 常用参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `-role` | host | host=建房间;client=加入 |
| `-ip` | 10.66.7.1/24 或 .2/24 | 本端隧道地址段;多房间并存时错开网段 |
| `-listen` | 47777 | host 监听的 UDP 端口 |
| `-peer` | 必填(client) | 对端 host:port |
| `-adapter` | EGLAN | 虚拟网卡名;同机多实例用不同名 |
| `-mtu` | 1400 | 隧道 MTU,勿超过路径 MTU |

## 5. 故障排查

| 现象 | 原因与处理 |
|---|---|
| `找不到 wintun.dll` | DLL 未放在 exe 同目录 |
| `创建网卡失败(权限被拒)` | 未以管理员运行 |
| `等待应答超时` | 对端未启动 / IP 写错 / 防火墙拦 UDP 47777;主机侧放行入站 UDP |
| ping 不通但握手成功 | 两端窗口需都保持打开;确认 `-ip` 网段一致 |
| 退出后残留 EGLAN 网卡 | 控制面板-网络连接中手动删除;下次正常退出会自动清理 |

## 6. 安全边界(P0)

- 通道密钥由 X25519 握手临时生成,进程退出即失效;长期身份绑定与房间码核验在 P1 接入。
- 当前任何人握上手即成为对端——同一局域网内可接受的信任模型,公网部署前必须完成房间码校验。
- 无遥测、无外联;除对端外不产生任何网络流量。
